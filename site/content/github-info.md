## Recent updates (November 2026)

### From the GitHub Changelog

- **[Wait for pull request events with GitHub CLI](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli)** – `gh` v2.105.0 supports GitHub Event Streams, so you (or your agents) can wait for a pull request to change with one command instead of polling.
- **[Customize GitHub Copilot for your team](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team)** – Team customizations are generally available, letting org teams share the Copilot plugins they rely on without each member repeating setup.
