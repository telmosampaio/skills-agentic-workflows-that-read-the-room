## Recent updates (November 2026)

### Copilot code review gets smarter

- **Adaptive effort** matches review depth to each pull request: quick passes for routine changes, deeper looks for risky ones.
- Reviews can use context from related repositories and flag exposed secrets before merge.
- Source: [Copilot code review: Adaptive effort, secret detection, and more](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more) (GitHub Changelog)

### Dependabot dismissal requests last longer

- With delegated alert dismissal, requests now stay open for one year instead of one week, so reviewers have more time to respond.
- Source: [Dependabot alert dismissal requests now last one year](https://github.blog/changelog/2026-11-16-dependabot-alert-dismissal-requests-now-last-one-year) (GitHub Changelog)

### Learn agent skills

- Agent skills are reusable instruction bundles that work across agents. Start with [Build once, run on any agent: A practical guide to agent skills](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/) (GitHub Blog).
- Browse community agents, instructions, and skills at [Awesome GitHub Copilot](https://awesome-copilot.github.com/).
