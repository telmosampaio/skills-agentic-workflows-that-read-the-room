## Recent updates worth trying

Updated from the GitHub Changelog, GitHub Blog and Awesome Copilot (November 2026).

### Collaboration

- [Issue statuses and repository boards (public preview)](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview): track issue progress with boards inside a repository.
- [New pull request overview page (public preview)](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview): a clearer summary of a PR's state; see also the [follow-up improvements](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview).
- [Pin favorite repositories to your dashboard](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard) for quick access.
- [Wait for pull request events with GitHub CLI](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli): script around PR checks and reviews from the terminal.
- [Issue types and fields for personal accounts](https://github.blog/changelog/2026-11-11-issue-types-and-fields-are-available-for-personal-accounts).

### GitHub Copilot

- [Customize GitHub Copilot for your team](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team): share instructions and customizations across a team.
- [Secret scanning on demand for developers and agents](https://github.blog/changelog/2026-11-17-secret-scanning-on-demand-for-developers-and-agents): check changes for leaked secrets before you push.
- [Copilot code review: adaptive effort, secret detection and more](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more).
- Guides: [Build once, run on any agent: agent skills](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/), [A developer's guide to agentic engineering](https://github.blog/ai-and-ml/github-copilot/beyond-code-generation-a-developers-guide-to-agentic-engineering/) and [How AI code generation works](https://github.blog/ai-and-ml/generative-ai/how-ai-code-generation-works/).

### GitHub Actions and security

- [Secret scanning detects secrets in Actions workflow logs](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs).
- [Actions for ARM32 Linux and Windows retirement](https://github.blog/changelog/2026-11-12-actions-for-arm32-linux-windows-retirement).
