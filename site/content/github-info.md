## Recent updates (November 2026)

### GitHub Actions and security

- **`pull_request_target` blocked by default from December 2, 2026** in public repositories unless an Actions event policy allows it. Review workflows that rely on it. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Secret scanning now detects secrets in Actions workflow logs.** Source: [GitHub Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs)

### Collaboration basics

- **New pull request overview page (public preview)** for a faster view of a PR's state. Sources: [announcement](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview), [improvements](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview)
- **Pin favorite repositories to your dashboard.** Source: [GitHub Changelog](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard)
- **GitHub CLI can wait for pull request events** with a single command (`gh` v2.105.0) instead of polling. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli)
