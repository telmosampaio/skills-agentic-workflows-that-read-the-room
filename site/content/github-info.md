# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates (November 2026)

### From the GitHub Changelog

- [Issue statuses and repository boards (public preview)](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview): track issue progress with statuses and boards scoped to a single repository.
- [Pin your favorite repositories to your dashboard](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard): quick access to the repos you use most.
- [Wait for pull request events with GitHub CLI](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli): script around PR events from the terminal.
- [Improvements to the pull request overview (public preview)](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview): a better starting point when reviewing PRs.
- [More predictable notifications on GitHub.com](https://github.blog/changelog/2026-11-24-more-predictable-notifications-on-github-com): easier to keep up with what needs your attention.
- [Secret scanning on demand for developers and agents](https://github.blog/changelog/2026-11-17-secret-scanning-on-demand-for-developers-and-agents): check for leaked secrets before you push.
- [Customize GitHub Copilot for your team](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team): share instructions and customizations across a team.
- [Let GitHub Copilot interact with your browser](https://github.blog/changelog/2026-11-17-let-github-copilot-interact-with-your-browser): Copilot can help test and debug web apps.
